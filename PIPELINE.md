Как исходники с телефона превращаются в готовый ролик с оценкой удержания внимания.
Тяжёлое видео едет через Google Drive, Telegram — тонкий «пульт» (только текст-команды).

```
iPhone ──auto──▶ Google Drive ──читает──▶ Claude ──▶ reels.json ──▶ reels.html
 съёмка          00 Исходники            классификация    оценка       страница-инструмент
   │                 │                     монтаж-план      удержания        │
   │                 │                                                       ▼
   └─ Telegram ◀── уведомление «новый исходник, тема: ОКК, монтировать?» ── n8n
      команда ──────────────────────────────────────────────▶ запуск монтажа
```

Почему не Telegram для видео: Telegram-**бот** может скачать файл максимум 20 МБ и отправить 50 МБ
(лимит Bot API). Ролики от 200 МБ через бота не проходят. На Drive лимита на размер нет.

## 1. Заливка с iPhone → Drive «00 Исходники» (настройка 5 мин, дальше 1 тап)

1. Поставь **Google Drive** из App Store, войди под `vlad.is.work.24.7@gmail.com`.
   Диск появится как папка в приложении **Файлы**.
2. Открой **Команды** (Shortcuts) → создать новую → назови **«→ Исходники»**.
3. Действия внутри команды:
   - **Принять из «Поделиться»** → тип: Медиа / Видео (Receive Media from Share Sheet).
   - **Сохранить файл** (Save File) → место = Google Drive → `АСП — Сериал 200 компаний` →
     `00 Исходники (съёмки)`.
   - У «Сохранить файл» отключи **«Спрашивать, куда сохранять»** (Ask Where to Save = Off).
4. В настройках команды включи **«Показывать в разделе Поделиться»** (Show in Share Sheet).
5. (бонус) Настройки iOS → Универсальный доступ → **Касание сзади** → Двойное касание →
   выбери команду «→ Исходники».

**Использование:** снял ролик → «Поделиться» → **«→ Исходники»** (или двойной тап по спинке
телефона). Видео заливается в фоне, размер значения не имеет.

## 2. Telegram-пульт через n8n (текст, не видео)

Рабочий процесс в n8n:
- **Google Drive Trigger** — событие «новый файл в папке `00 Исходники`».
- → **Telegram (sendMessage)** — тебе прилетает:
  `🎬 Новый исходник: <имя>, <размер>. Предв. тема: <ОКК / метрики / …>. Монтировать? /go`
- Твой ответ-команда (`/go`, `/skip`, `/tag ОКК`) → **Telegram Trigger** → вебхук →
  сигнал на разбор и монтаж.

Telegram носит только текст: уведомления о новых исходниках и твои короткие команды.
Видео он не трогает — оно уже на Drive.

## 3. Классификация по темам (Claude)

Как только клип в «00 Исходники», он разбирается по контент-пилонам:
- ОКК / аналитика диалогов
- Метрики отдела продаж
- AI-автоматизация для РОП
- Кейсы и разборы
- Личное / мотивация

Уровни точности:
- **Сейчас:** по имени файла + метаданным + короткой подписи (если добавишь).
- **Дальше:** транскрибация речи из ролика → классификация по смыслу автоматически;
  `virality_predictor` — предоценка хука на входе. (требует кредитов Higgsfield)

Итог сводится в раздел «Инбокс» на `reels.html`: клипы разложены по темам → выбор → монтаж.

## 4. Монтаж и оценка (Claude → reels.json → reels.html)

Исходник → сценарий твоим стилем → план монтажа (нарезка, субтитры, вставки, динамика, хук)
→ **Attention Score** по методике (6 компонентов) → варианты A/B с оценкой.
Модель данных и методика — в `reels.json`, отображение — в `reels.html`.

## 5. Финальный рендер — Higgsfield (в самом конце)

Утверждённый вариант уходит в рендер: клонирование голоса (`create_voice`),
озвучка (`generate_audio`), сборка вертикали с субтитрами и вставками
(`shorts_studio_create` / `personal_clipper`), финальный чек хука (`virality_predictor`).
Требует кредитов Higgsfield. Готовый ролик кладётся в `01 Готовые ролики`.

## 6. Замыкание цикла (факт из соцсетей)

После публикации: досмотр 3 c, средний досмотр %, до конца, просмотры, сохранения из
Instagram/TikTok Insights → вписываются в `reels.json` → факт ложится зелёной линией
поверх прогноза в `reels.html`. Так оценка калибруется под реальную аудиторию.
