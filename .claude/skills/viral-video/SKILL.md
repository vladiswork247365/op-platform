# Конвейер виральных роликов АСП

Пайплайн из 5 шагов: **данные → угол → сценарий → рендер (Higgsfield) → сохранение (Drive)**.
Всё вертикальное 9:16, длина 15–35 сек, язык — русский, аудитория — РОП-ы и владельцы отделов продаж (Казахстан).

## Предпосылки (проверь один раз)

Два коннектора claude.ai должны быть включены **в этом чате** (иконка коннекторов → включить):

| Коннектор | Роль | Как проверить |
|---|---|---|
| **Higgsfield** | генерация видео | `ListConnectors` → `enabledInChat: true`. Если false — попроси пользователя включить его в настройках коннекторов чата. |
| **Google Drive** | хранение сценариев и ссылок на ролики | обычно уже включён |

Инструменты Higgsfield не видны, пока коннектор выключен. После включения загрузи их схемы:
`ToolSearch("higgsfield video generate")`. Названия инструментов могут отличаться — бери их из
результата ToolSearch, не выдумывай.

Если Higgsfield включить нельзя — выполни шаги 1–3 (данные → угол → сценарий) и отдай
пользователю готовый сценарий + промпты для ручного рендера. Это тоже полезный результат.

## Шаг 1 — данные

Всегда работай на свежих данных из корня репозитория:
- `live.json` — `stats` + `authors[]` с полями `points`, `msgs`, `cats` (экспертный/кейс/вопрос/шум/нарушение/обычное), `act{d,w,m}` (баллы за день/неделю/месяц).
- `profiles.json` — карточки `{slug: {phone, niche, role, company, what, ...}}`.

## Шаг 2 — выбрать угол

Запусти хелпер — он вернёт готовые виральные углы с реальными числами:

```bash
python3 .claude/skills/viral-video/scripts/angles.py           # человекочитаемо
python3 .claude/skills/viral-video/scripts/angles.py --json     # для дальнейшей обработки
```

Углы, которые он считает:
- **top_week** — «Топ недели по активности» (самый сильный виральный формат: движуха, соревнование).
- **experts** — «Эксперты сообщества» (кто даёт больше всего экспертных сообщений).
- **cases** — «Разбор кейсов» (реальные истории → максимальная досматриваемость).
- **risers** — «Ворвались в рейтинг» (моментум недели: новички с резким ростом → «а что, так можно?»).

Выбери один угол под задачу. Если пользователь не указал — по умолчанию **top_week**.
Для угла про конкретного человека подтяни его карточку из `profiles.json` (ниша/роль/компания),
чтобы ролик был персональным.

Не публикуй `phone` из данных — телефоны только для внутренней идентификации, в ролик их не выносить.

## Шаг 3 — сценарий

Сгенерируй сценарий строго по этой структуре (шаблон рядом: `scripts/script_template.md`):

1. **HOOK (0–3 сек)** — цифра или интрига в первом кадре. Примеры:
   «209 баллов за неделю. Один человек.» / «94 реальных кейса за месяц. Смотри кто.»
2. **BODY (3–25 сек)** — 3–5 шотов. Для каждого: `визуал` (что в кадре), `текст на экране`, `озвучка (VO)`.
   Используй настоящие имена и числа из угла. Динамика: смена кадра каждые 2–4 сек.
3. **CTA (последние 3–5 сек)** — призыв: вступай в АСП / проверь свой рейтинг на platform.systemop.top.
4. **CAPTION** — подпись для соцсети: 1–2 строки + 5–8 хэштегов
   (#системныепродажи #РОП #отделпродаж #АСП #Казахстан + тематические).
5. **HIGGSFIELD PROMPTS** — на каждый шот отдельный английский промпт для видео-модели
   (стиль: dark premium, red/gold accents #E8000A/#FFD700 — фирменные цвета платформы, вертикаль 9:16,
   кинематографично, motion graphics с цифрами).

Тон: энергичный, деловой, без «воды». Числа — крупно. Один ролик = один герой/одна мысль.

## Шаг 4 — рендер через Higgsfield

Только если коннектор включён:
1. `ToolSearch("higgsfield video generate image to video")` — загрузи инструменты.
2. На каждый шот вызови генерацию с соответствующим английским промптом (9:16).
3. Собери ссылки/файлы результатов. Если Higgsfield умеет только image-to-video — сначала
   сгенерируй кадры, затем оживи; действуй по фактической схеме инструментов.

Если инструмент упал или недоступен — не выдумывай результат: сообщи об ошибке и отдай сценарий
для ручного рендера.

## Шаг 5 — сохранить в Google Drive

Сохрани артефакты, чтобы ничего не потерялось:
1. Создай текстовый файл со сценарием: `create_file` (Google Drive) — имя вида
   `АСП_виралка_<угол>_<дата>.md`, содержимое = готовый сценарий из шага 3.
2. Если из Higgsfield пришли ссылки на видео — добавь их в этот же файл.
3. Верни пользователю: краткое описание ролика, ссылку на файл в Drive и (если есть) ссылки на видео.

## Итог пользователю

Всегда заканчивай коротким резюме: какой угол взят, какие числа/герои, где лежит сценарий,
отрендерилось ли видео. Если что-то из коннекторов было выключено — прямо скажи, что осталось
включить, чтобы пройти пайплайн до конца.
