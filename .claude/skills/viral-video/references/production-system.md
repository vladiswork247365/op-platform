# Производственная система роликов АСП

Полная схема работы, учитывающая ограничения окружения. Читать перед производством серии.

## Ограничения окружения (проверено)

Сессия Claude Code работает в закрытом сетевом контуре (egress по белому списку).
Что доступно, а что нет:

| Канал | Статус | Как используем |
|---|---|---|
| Higgsfield **MCP-коннектор** | ✅ работает | генерация image/video/audio идёт через claude.ai, не через egress сессии |
| Google Drive MCP | ✅ работает | документы/данные (не тяжёлое видео — отдаётся base64) |
| pypi / github | ✅ | установка ffmpeg (imageio-ffmpeg), Pillow |
| **api.trendsee.io** | ❌ 403 | живой поиск ИЗ сессии невозможен → работаем по выгрузкам (см. ниже) |
| **CDN Higgsfield** (скачивание результатов) | ❌ 403 | файлы Higgsfield нельзя утащить в локальный ffmpeg → ИИ-ролики собираем внутри Higgsfield |
| внешние TTS (bing/edge-tts) | ❌ 403 | озвучку берём из Higgsfield `generate_audio` или из своего голоса |

Практический вывод: **два независимых «цеха» сборки** (ниже), выбор — по типу выпуска.

## Цех A — «Свои съёмки» (сборка локальным ffmpeg)

Для фотореалистичных выпусков (кейсы, закулисье) — стиль как у @kudryavtsevtony.

Поток:
1. Я даю сценарий + **шот-лист** (что снять, по секундам) + тексты субтитров.
2. Пользователь снимает реальное видео, режет каждый кадр до нужных секунд,
   экспортирует 1080p H.264 → **каждый кусок ≤ 30 МБ** → грузит в чат.
   (200 МБ слать не нужно: один кадр = 3–6 сек в 1080p ≈ 5–15 МБ.)
3. Я собираю через `assemble_reel.py`/ffmpeg: **голос + фоновая музыка + субтитры-по-словам + склейка**.
   Только этот цех умеет подмешать музыку под голос в сам файл.
4. Пользователь добавляет трендовый звук при желании и публикует.

Голос для цеха A: либо свой (запись на телефон), либо ИИ (сгенерить в Higgsfield → но файл
не скачать в сессию; проще свой голос). Музыка: свой трек (я подмешаю) или трендовый звук при заливке.

## Цех B — «ИИ / Higgsfield» (сборка на сервере Higgsfield)

Для стилизованных выпусков (инсайты, вехи, факты).

Поток:
1. Тяжёлые исходники (если нужны как вход) грузятся **прямо в Higgsfield** (`media_upload_widget` /
   `media_import_url`) — минуя лимит чата 30 МБ.
2. Генерация: `generate_image` (nano_banana_pro, ~2 кр), `generate_video` (gemini_omni/Kling),
   `generate_audio` (seed_audio, русский голос).
3. Сборка **на сервере** через `explainer_video`: склейка клипов + голос + **вжатые субтитры по словам**
   (Whisper-синхрон, шрифты patrick/caveat/marker/anton). Ограничение воркфлоу `video-explainer` —
   только НЕ-фотореализм (анимация/графика). Фоновой музыки нет.
4. Пользователь скачивает готовый MP4 из своего аккаунта Higgsfield.

Стоимость Higgsfield: картинка ~2 кр, видео-блок дороже; `get_cost:true` — преднапросмотр без списания.
Триал Plus: 100 кредитов, авто-списание через 3 дня (отменяется `cancel_trial_auto_renewal`).

## trendsee — разведчик трендов (по выгрузкам)

Живой API из сессии закрыт (403). Схема работы:
1. Пользователь запускает `trendsee.py search '<ниша>' --last-days 30 --save file.json` **на своём компе**.
2. Грузит JSON в чат (выгрузки крошечные, ~50 КБ — лимит 30 МБ не мешает).
3. Я анализирую: сортировка по `viral_coef` (во сколько раз просмотры превысили норму блогера),
   `er` (вовлечённость), `duration`, крючки в `caption` → выдаю паттерны и готовые сценарии под них.

Полезные поля поста: `viral_coef`, `er`, `play_count`, `duration`, `caption`, `social_url`,
`social_type`, `subscribers_viral_coef`. Фильтры CLI: niche/format/face_presence/editing_complexity и др.

## Сериал «200 компаний»

Сквозной формат: подключение 200 компаний к панели для РОП-ов, счётчик «Компания N из 200».

Типы выпусков (чередуем, цех в скобках):
- **Кейс онбординга** (A): подключили компанию → что нашли в диалогах → результат.
- **Закулисье** (A): что видит РОП в панели, как работает.
- **Инсайт** (B): одна ошибка ОП, всплывшая у N компаний.
- **Веха** (B): 10 / 50 / 100 / 200 — итоги, цифры, эмоции.

Крючок каждого выпуска: цифра + интрига. CTA: platform.systemop.top.
Формат: вертикаль 9:16, 30–45 сек. Тексты и числа — из реальных данных (live.json/profiles.json/кейсы),
ничего не выдумывать.

## Петля производства одного выпуска

trendsee-тренд → сценарий + шот-лист + субтитры (я) → съёмка/загрузка (пользователь) →
сборка (цех A локально / цех B в Higgsfield) → трендовый звук + публикация со счётчиком (пользователь).
