# Качество картинки

## Сначала — бесплатно и локально

Апскейл кредитами нужен не всегда. Если исходник снят на нормальный телефон в 1080p,
90% «мутности» лечится резкостью, шумодавом и цветом — за 0 кредитов.

### Диагностика
```bash
ffprobe -v error -select_streams v:0 -show_entries stream=width,height,bit_rate,codec_name \
  -of default=nw=1 work/ep014_voice.mp4
```
- Ширина < 1080 → апскейл оправдан.
- Ширина ≥ 1080, но битрейт низкий → проблема в компрессии, апскейл не спасёт, помогут
  шумодав + резкость.

### Резкость + шумодав + цвет — одной командой
```bash
ffmpeg -hide_banner -loglevel error -i work/ep014_voice.mp4 -vf \
"hqdn3d=1.5:1.5:6:6,unsharp=5:5:0.8:5:5:0.0,eq=contrast=1.06:saturation=1.10:gamma=0.98" \
 -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p -c:a copy work/ep014_up.mp4 2>> work/ffmpeg.log
```
`unsharp` выше 1.2 даёт «звенящие» контуры — выглядит хуже, чем мягкая картинка.

### Тёмный кадр (снято против окна, лицо в тени)
```bash
ffmpeg -i in.mp4 -vf "curves=preset=lighter,eq=brightness=0.04:contrast=1.10:saturation=1.05" -c:a copy out.mp4
```

### Пересвет
```bash
ffmpeg -i in.mp4 -vf "eq=brightness=-0.05:contrast=1.12,curves=preset=darker" -c:a copy out.mp4
```

### Тёплая «плёночная» база под дневниковый сериал
```bash
ffmpeg -i in.mp4 -vf \
"eq=contrast=1.08:saturation=1.06,colorbalance=rs=0.03:gs=0.0:bs=-0.03:rm=0.02:bm=-0.02,\
noise=alls=3:allf=t,vignette=PI/5" -c:a copy out.mp4
```
Один цветовой ключ на весь сериал — это часть узнаваемости, меняй его только на вехах.

### Стабилизация дрожащей съёмки с рук
```bash
ffmpeg -i in.mp4 -vf vidstabdetect=shakiness=6:accuracy=15 -f null -
ffmpeg -i in.mp4 -vf vidstabtransform=smoothing=22:zoom=2,unsharp=5:5:0.5 -c:a copy out.mp4
```

### Горизонталь → вертикаль
Кроп по центру (если объект в центре):
```bash
ffmpeg -i in.mp4 -vf "crop=ih*9/16:ih,scale=1080:1920,setsar=1" -c:a copy out.mp4
```
Умное кадрирование, когда объект не в центре, — Higgsfield `reframe`.

## Когда нужны кредиты

| Задача | Инструмент | Когда оправдано |
|---|---|---|
| Апскейл видео до 2K/4K | `upscale_video` | исходник < 1080p, или нужен 4K под площадку |
| Апскейл фото | `upscale_image` | обложка, кадр-плашка, скриншот метрики |
| Умный рефрейм 16:9 → 9:16 | `reframe` | объект гуляет по кадру, центральный кроп режет |
| Удаление фона | `remove_background` | нужен вырез объекта поверх другого фона |
| Расширение кадра | `outpaint_image` | кадр обрезан, нужен воздух сверху/снизу |

Апскейл — **последний** тяжёлый шаг перед субтитрами. Апскейлить черновик,
который ещё будет перемонтирован, — выброшенные кредиты.

## Проверка глазами

```bash
for t in 2 12 28; do ffmpeg -hide_banner -loglevel error -ss $t -i work/ep014_up.mp4 \
  -frames:v 1 work/q_$t.jpg; done
```
Прочитай кадры через Read и сравни с исходными. Смотри на:
- лицо не «пластиковое» после шумодава;
- нет ореолов вокруг контуров от резкости;
- кожа естественного оттенка после цветокоррекции;
- тени не залиты в чёрное, света не выбиты в белое.

Если стало хуже — откатись к более мягким параметрам. Переобработка заметнее, чем
недообработка: зритель прощает мягкую картинку и не прощает «перешарп».
