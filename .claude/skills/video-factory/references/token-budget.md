# Бюджет токенов контент-фабрики

Цель: полный день (исходники → готовый ролик + текст) укладывается в разумный контекст,
а не съедает окно на логах ffmpeg и транскриптах.

## Жёсткие правила

1. **Никогда не читай видео/аудио файл в контекст.** Только метаданные через `ffprobe`.
2. **Кадры — выборочно.** Из 3-минутного исходника хватает 8–14 кадров.
   Не «каждую секунду». Правило: 1 кадр на 10–15 с + отдельно кадры на резких сменах сцены.
3. **Транскрипт — не в чат.** Пиши в `notes/transcript.srt`, в контекст бери только
   выжимку (тезисы + тайм-коды сильных фраз) в `notes/context.md`.
4. **Логи ffmpeg — в файл.**
   ```bash
   ffmpeg -hide_banner -loglevel error -i in.mp4 ... out.mp4 2> work/ffmpeg.log; echo "rc=$?"
   ```
   В контекст — только `rc=` и, если ошибка, `tail -3 work/ffmpeg.log`.
5. **`references/` подгружай по факту нужды**, а не «чтобы было». Одна задача — один справочник.
6. **Не пересказывай пользователю то, что уже в файле.** Скажи «записал в notes/script.md»
   и покажи только хук и первые 2 строки.
7. **Не поллинг вслепую.** У Higgsfield-задач (`*_status`) — интервал от 30 с, не чаще.
   Между проверками не дублируй контекст задачи.

## Что можно делать бесплатно локально (не тратя кредиты Higgsfield)

| Задача | Локально |
|---|---|
| Нарезка, склейка, переходы | ffmpeg |
| Вырезание пауз | ffmpeg `silencedetect` |
| Кроп 9:16, ресайз | ffmpeg `crop`/`scale` |
| Цвет, резкость, шумодав | ffmpeg `eq`/`unsharp`/`hqdn3d` |
| Субтитры, вжигание | whisper.cpp + ffmpeg `ass` |
| Обложка | ffmpeg extract frame |

Кредиты Higgsfield нужны только там, где без генерации не обойтись:
AI-анимация, клон голоса, апскейл до 4K, дубляж, прогноз виральности, постинг.
Сначала спроси себя: «это делает ffmpeg?» — и если да, не трать кредиты.

## Модельный режим

Тяжёлое творческое (сценарий, арка сериала) — думай нормально.
Механику (переименование, склейка, проверка статуса) — делай без рассуждений, одной командой.
