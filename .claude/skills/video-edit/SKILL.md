# Монтаж

## Правило номер один

Всё, что можно сделать локально в ffmpeg, делается локально. Генеративные инструменты —
только там, где нужен кадр, которого не существует.

## Порядок

1. Прочитай `notes/script.md` — там таблица «время / реплика / источник» — это и есть EDL.
2. Проверь ffmpeg: `ffmpeg -version | head -1`. Нет — скажи как поставить, не выдумывай обходы.
3. Нарежь фрагменты → склей → ритм → переходы → музыка (если без озвучки).
4. Отдай `work/epNNN_cut.mp4`, обнови `state.json`.

## Нарезка фрагментов

Точный рез (перекодирование, кадровая точность — то, что нужно для коротких роликов):
```bash
ffmpeg -hide_banner -loglevel error -ss 00:00:14.0 -to 00:00:19.5 -i raw/clip.mp4 \
  -c:v libx264 -crf 18 -preset medium -c:a aac -b:a 192k work/s01.mp4 2>> work/ffmpeg.log
```
`-ss` **до** `-i` — быстро; для кадровой точности при перекодировании этого достаточно.

## Склейка

```bash
printf "file 's01.mp4'\nfile 's02.mp4'\nfile 's03.mp4'\n" > work/list.txt
ffmpeg -hide_banner -loglevel error -f concat -safe 0 -i work/list.txt -c copy work/cut_raw.mp4
```
`-c copy` работает только если все куски в одном формате/разрешении/fps. Иначе — приведи
их к общему виду при нарезке (одинаковые `-s`, `-r`, `-pix_fmt yuv420p`).

## Вырезание пауз — главный рычаг динамики

Найди тишину:
```bash
ffmpeg -hide_banner -i work/cut_raw.mp4 -af silencedetect=noise=-32dB:d=0.35 -f null - 2>&1 \
  | grep silence_ > work/silence.txt
```
Дальше собери список «говорящих» интервалов и нарежь по ним. Оставляй **0.08–0.12 с**
воздуха с каждой стороны — вырезанные встык фразы звучат неестественно.

Ролик, из которого вырезаны паузы, ощущается вдвое короче при той же длине.

## Ритм

- Средняя длина плана в вертикальном ролике: **1.2–2.5 с**. Дольше 4 с — только если в кадре
  реально что-то происходит.
- Меняй крупность соседних планов. Два одинаковых плана подряд читаются как ошибка монтажа.
- В первые 3 секунды — минимум 2 склейки.

## Переходы

По умолчанию — **жёсткий рез**. Он не отвлекает и не стоит ничего.
Эффектный переход уместен 1–2 раза на ролик, на смысловом повороте.

Готовые команды (xfade, whip pan, glitch, speed ramp, match cut, маскированные переходы)
и точные фильтры — в `references/ffmpeg-recipes.md`. Подгружай, когда переход реально нужен.

## Музыка (если ролик без озвучки)

```bash
ffmpeg -hide_banner -loglevel error -i work/cut.mp4 -i assets/music.mp3 \
  -filter_complex "[1:a]volume=0.18,afade=t=out:st=38:d=2[m];[0:a][m]amix=inputs=2:duration=first[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac work/cut_music.mp4
```
Если есть голос — музыка под ducking, см. `video-voice`.

## Проверка перед сдачей

- [ ] Первые 1.5 с совпадают с хуком из сценария?
- [ ] Нет планов длиннее 4 с без движения?
- [ ] Нет провалов звука на склейках?
- [ ] Длина в целевом диапазоне (обычно 30–45 с)?
- [ ] Последний кадр — петля на завтра, а не обрыв?
