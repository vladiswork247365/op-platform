# 🎬 VIDEO — контент-фабрика (категория скиллов)

Пак скиллов для ежедневного производства вертикального контента (Reels / Shorts / TikTok)
и ведения сериала-сторителлинга «путь к цели».

Все скиллы категории начинаются с префикса `video-` — в списке скиллов они идут одним блоком.
Все слэш-команды лежат в неймспейсе `/video:` — в меню команд это отдельная категория.

## Скиллы

| Скилл | Что делает | Когда срабатывает |
|---|---|---|
| `video-factory` | **Хаб.** Ежедневный конвейер, состояние дня, маршрутизация в остальные скиллы | «делаем контент», «что сегодня», «выпуск» |
| `video-ingest` | Смотрит отснятый материал **глазами**: кадры, речь, тайм-коды, лучшие дубли | «посмотри что я снял», «разбери исходники» |
| `video-series-bible` | Библия сериала: цель, арка, что уже было, чтобы не повторяться | «что было в прошлой серии», «арка» |
| `video-script` | Сценарий дня: хук, структура, текст, описание, хештеги | «напиши текст на день», «сценарий» |
| `video-edit` | Монтаж: нарезка, вырезание пауз, ритм, переходы, b-roll | «смонтируй», «нарежь», «переходы» |
| `video-subtitles` | Субтитры: SRT/ASS, karaoke по словам, вжигание, стили | «субтитры», «титры», «captions» |
| `video-voice` | Озвучка: TTS, клон голоса, дубляж, сведение с музыкой | «озвучь», «голос», «дубляж» |
| `video-motion` | AI-анимация и генеративный b-roll, motion control | «анимация», «сгенерируй сцену» |
| `video-enhance` | Качество: апскейл 2K/4K, резкость, цвет, кроп 9:16, фон | «улучши качество», «апскейл» |
| `video-publish` | Упаковка и постинг: прогноз виральности, трендовый звук, TikTok | «выложить», «опубликовать» |

## Команды

```
/video:day       — прогнать весь день от исходников до готового ролика
/video:ingest    — разобрать отснятый материал
/video:script    — сценарий и текст дня
/video:edit      — монтаж
/video:subs      — субтитры
/video:voice     — озвучка
/video:motion    — AI-анимация / b-roll
/video:enhance   — качество картинки
/video:publish   — упаковка и публикация
/video:bible     — библия сериала
/video:status    — что готово, что нет
```

## Установка

Скиллы уже работают в этом репозитории (проектные скиллы `.claude/skills/`).
Чтобы они были доступны **во всех проектах** на вашей машине:

```bash
bash .claude/skills/install.sh
```

Скрипт скопирует пак в `~/.claude/skills/` и команды в `~/.claude/commands/video/`.

## Что требуется

- **ffmpeg + ffprobe** — локальный монтаж, субтитры, сведение звука.
  `brew install ffmpeg` (macOS) / `sudo apt install ffmpeg` (Linux) / `winget install ffmpeg` (Windows)
- **Higgsfield MCP** — генерация, апскейл, озвучка, анализ видео, постинг в TikTok. Уже подключён.
- *(опционально)* **whisper.cpp / faster-whisper** — офлайн-распознавание речи для субтитров без расхода кредитов.

## Экономия токенов

Пак построен на progressive disclosure: тело каждого `SKILL.md` короткое,
тяжёлые справочники (`references/*.md`) подгружаются только когда реально нужны.
Правила расхода — в `video-factory/references/token-budget.md`.
