# Озвучка и звук

## Что чем делается

| Задача | Инструмент |
|---|---|
| Синтез речи по тексту | Higgsfield `generate_audio` |
| Клон своего голоса | `create_voice` → затем `generate_audio` с этим voice_id |
| Список доступных голосов | `list_voices` |
| Замена голоса в готовой записи | `voice_change` |
| Дубляж ролика на другой язык | `dubbing` |
| Сведение, громкость, ducking | ffmpeg (локально, бесплатно) |

Имена инструментов даны без префикса MCP-сервера — в вызове это `mcp__Higgsfield__generate_audio`
(если сервер подключён под другим именем — префикс будет другим, тулы те же).

## Клон голоса — делается один раз

Для сериала своим голосом:
1. Запиши 1–3 минуты чистой речи без музыки и шума, в одном темпе.
2. Загрузи через `media_upload_widget` (type=audio).
3. `create_voice` / `create_voice_from_confirmed_audio` → получишь `voice_id`.
4. Запиши `voice_id` в `content/series-bible.md` — он нужен каждый день.

Дальше вся озвучка идёт этим id, и сериал звучит одинаково от выпуска к выпуску.

## Текст для озвучки

Берётся из `notes/script.md` — колонка реплик, без пометок монтажу.

Правила подготовки текста под TTS:
- Числа пиши словами там, где важно произношение: «17» → «семнадцать».
- Латиницу и аббревиатуры — транслитом: «CTR» → «си-ти-ар».
- Паузы — точками и абзацами, не многоточиями подряд.
- Одно предложение = одна мысль. Длинные периоды синтез читает монотонно.

## Сведение (локально)

Голос + музыка с автоматическим приглушением музыки под речь (ducking):
```bash
ffmpeg -hide_banner -loglevel error -i work/ep014_cut.mp4 -i work/voice.mp3 -i assets/music.mp3 \
  -filter_complex "\
   [1:a]loudnorm=I=-16:TP=-1.5:LRA=11,apad[v]; \
   [2:a]volume=0.22[m]; \
   [m][v]sidechaincompress=threshold=0.05:ratio=8:attack=5:release=280[mduck]; \
   [v][mduck]amix=inputs=2:duration=first:dropout_transition=0[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k work/ep014_voice.mp4 2>> work/ffmpeg.log
```

Что здесь важно:
- `loudnorm I=-16` — стандарт громкости для соцсетей. Без нормализации ролик будет
  тише чужих в ленте, и его пролистают.
- `sidechaincompress` — музыка автоматически проседает, когда звучит голос. Это то,
  что отличает профессиональное звучание от «музыка забивает речь».
- `volume=0.22` для музыки — стартовая точка, подстраивай на слух.

Убрать оригинальный звук камеры и оставить только озвучку:
```bash
ffmpeg -i work/cut.mp4 -i work/voice.mp3 -map 0:v -map 1:a -c:v copy -c:a aac -shortest out.mp4
```

Шумодав для записи с телефона:
```bash
ffmpeg -i in.mp4 -af "highpass=f=90,lowpass=f=12000,afftdn=nr=12:nf=-28,loudnorm=I=-16:TP=-1.5" -c:v copy out.mp4
```

## Дубляж на другой язык

`dubbing` принимает готовое видео и целевой язык, сохраняя голос. Для сериала это способ
удвоить охват без пересъёмки. После дубляжа субтитры генерируются заново — под новую дорожку.

## Проверка

- [ ] Громкость нормализована (`I=-16`)?
- [ ] Музыка не забивает голос на самых тихих словах?
- [ ] Нет обрыва звука в конце (`apad` / `-shortest` отработали)?
- [ ] Голос совпадает по длине с видеорядом — если озвучка длиннее, монтаж надо подрезать
      или растянуть планы, а не ускорять речь.

## Порядок

Звук сводится **до** `video-enhance` и **до** `video-subtitles`: апскейл перекодирует
контейнер, а субтитры генерируются по финальной звуковой дорожке.
