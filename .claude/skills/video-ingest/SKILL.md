# Разбор материала: увидеть и услышать

Задача — превратить сырое видео в текстовый контекст, по которому можно писать сценарий,
не пересматривая исходники.

## 1. Метаданные (всегда первым)

```bash
ffprobe -v error -select_streams v:0 \
  -show_entries stream=width,height,r_frame_rate,duration,codec_name \
  -show_entries format=duration,size -of default=nw=1 raw/clip.mp4
```

Запомни: длительность, разрешение, ориентация (вертикаль/горизонталь), fps.
Ориентация решает, понадобится ли `video-enhance` для кропа в 9:16.

## 2. Смотреть глазами — кадры

Извлеки кадры и **прочитай их через Read** (изображения читаются напрямую).

Равномерная сетка — 1 кадр на 10–15 секунд:
```bash
mkdir -p work/frames
ffmpeg -hide_banner -loglevel error -i raw/clip.mp4 \
  -vf "fps=1/12,scale=480:-1" work/frames/f_%03d.jpg 2> work/ffmpeg.log; echo "rc=$?"
```

Плюс кадры на сменах сцены (там, где реально что-то происходит):
```bash
ffmpeg -hide_banner -loglevel error -i raw/clip.mp4 \
  -vf "select='gt(scene,0.3)',scale=480:-1" -vsync vfr work/frames/scene_%03d.jpg 2>> work/ffmpeg.log
```

Читай **не больше 14 кадров** на клип. Если материала много — сначала сетка, и только
по подозрительным участкам добирай кадры точечно (`-ss` + `-frames:v 1`).

Для каждого кадра фиксируй: что в кадре, свет, композиция, эмоция, есть ли брак
(смаз, пересвет, палец на объективе, кривой горизонт).

## 3. Слушать — транскрипт с тайм-кодами

Локально и бесплатно, если стоит whisper.cpp / faster-whisper:
```bash
ffmpeg -hide_banner -loglevel error -i raw/clip.mp4 -vn -ac 1 -ar 16000 work/audio.wav
whisper-cli -m models/ggml-medium.bin -l ru -osrt -of notes/transcript work/audio.wav
```
Если whisper не установлен — скажи об этом прямо и предложи: (а) поставить его,
(б) прогнать через Higgsfield `video_analysis_create` (расходует кредиты, 3–5 минут,
на длинных видео точность падает — предупреди пользователя).

Транскрипт целиком в контекст **не тащи**. Из него нужны только:
сильные фразы с тайм-кодами, места запинок/пауз, самая цепкая первая фраза.

## 4. Собрать context.md

Пиши в `notes/context.md` по шаблону:

```markdown
# Контекст дня — {дата}, {эпизод}

## Что снято
{2–4 предложения: где, что происходит, настроение}

## Годные куски
| Тайм-код | Что | Почему берём |
|---|---|---|
| 00:12–00:19 | крупный план, «сегодня первый платёж» | эмоция, готовый хук |

## Брак / не брать
| Тайм-код | Проблема |
|---|---|
| 01:03–01:30 | пересвет от окна, лицо в тени |

## Сильные фразы (дословно)
- 00:14 «…» ← кандидат в хук
- 01:47 «…» ← кандидат в финал

## Визуал
Свет: … / Фон: … / Ориентация: … / Что просится b-roll'ом: …

## Событие дня для сериала
{одно предложение — что реально произошло, для series-bible}
```

## 5. Отдать дальше

Обнови `state.json`: `ingest: done`. Пользователю покажи **короткую сводку**:
сколько годного материала, 2–3 лучших момента с тайм-кодами, брак, и «событие дня».
Не пересказывай весь context.md — он уже на диске.

## Если материал не локальный

- YouTube-ссылка → Higgsfield `video_analysis_create(youtube_url=...)`, потом `video_analysis_status`.
- Загружен в Higgsfield → `media_upload_widget` даёт id, дальше `video_analysis_create(video_input_id=...)`.
- Лежит в Google Drive → `search_files` → `download_file_content`, дальше как с локальным.
