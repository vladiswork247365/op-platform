# AI-видео и анимация

Генерация стоит кредитов и времени. Правило: генерируй только кадр, которого **физически нет**
в отснятом материале и который нельзя заменить b-roll'ом с экрана / телефона.

## Инструменты

| Задача | Инструмент |
|---|---|
| Видео по тексту / по картинке | `generate_video` |
| Кадр-референс, персонаж, обложка | `generate_image` |
| Не знаю какая модель подойдёт | `models_explore(action:'recommend')` |
| Перенос движения, recast, puppeteer | `motion_control` |
| Каталог движений/действий | `animation_actions` |
| Пресеты стилей | `presets_show` |
| Персонажи для консистентности | `show_characters`, `show_reference_elements` |
| Снятое видео → AI-стилизованные шортсы | `shorts_studio_create` (+ `shorts_studio_list_presets`) |
| Нарративный объясняющий ролик | `explainer_video` (+ `get_explainer_presets`) |
| Статус задачи | `job_display`, `*_status` |

Перед многошаговым брифованным роликом (реклама, explainer, UGC, подкаст) сначала вызови
`get_workflow_instructions` без аргументов — посмотри каталог воркфлоу, потом загрузи нужный.

## Промпт для генеративного кадра

Рабочая структура: **субъект → действие → окружение → камера → свет → стиль**.

> Мужчина за столом закрывает ноутбук и откидывается на спинку, тёмная комната,
> свет только от монитора, медленный наезд камеры, кинематографично, 35mm, зерно плёнки

Что важно:
- **Одно действие на клип.** Две команды в промпте дают кашу.
- **Камера отдельной фразой**: «медленный наезд», «пролёт сбоку», «статичный штатив».
- **Свет отдельной фразой** — он даёт больше половины ощущения качества.
- Клип 3–5 с. Длиннее — модель теряет консистентность.
- Негативные формулировки работают плохо: описывай что нужно, а не чего не нужно.

## Консистентность персонажа в сериале

Если в анимационных вставках появляетесь «вы» или один и тот же герой:
1. Сгенерируй character sheet — перед этим вызови
   `get_workflow_instructions({workflow:"character-sheet"})` и следуй ей.
2. Сохрани референс, используй его во всех последующих генерациях.
3. Зафиксируй в `series-bible.md`: id персонажа, стиль, палитру.

Без этого герой будет меняться от серии к серии, и сериал развалится визуально.

## Оживление фото

`generate_video` с входным изображением: скриншот метрики, фото продукта, старое фото —
и лёгкое движение камеры. Это самый дешёвый способ получить b-roll, когда снимать нечего.

## Restyle снятого материала

`shorts_studio_create` берёт ваш ролик (4–120 с) и пересобирает в AI-стилизованные шортсы
по пресету. Хорошо работает как «спецвыпуск» на вехе арки — но не как ежедневный формат:
зритель дневникового сериала приходит за настоящим вами.

Стоимость можно узнать заранее: `shorts_studio_create(get_cost=true, duration_seconds=N)` —
без запуска задачи.

## Асинхронность

Все генерации — фоновые задачи. Запустил → получил id → опрашивай статус **не чаще раза
в 30 секунд**. Пока идёт генерация, занимайся монтажом остального: не жди простаивая.

Перед серией генераций проверь остаток: `balance` / `show_plans_and_credits`.

## Встраивание в монтаж

Сгенерированный клип складывается в `work/broll_NN.mp4` и вставляется через `video-edit`
(overlay или врезка). Приведи его к общим параметрам проекта, иначе склейка даст рассинхрон:
```bash
ffmpeg -i broll_raw.mp4 -vf "scale=1080:1920,setsar=1,fps=30" -pix_fmt yuv420p -an work/broll_01.mp4
```

## Мера

Генеративные вставки — приправа: 2–4 секунды на 40-секундный ролик. Сериал о реальном пути
держится на реальных кадрах; анимация нужна там, где надо показать невидимое —
метафору, будущее, схему, воспоминание.
