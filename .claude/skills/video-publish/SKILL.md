# Упаковка и публикация

## 1. Финальный экспорт

```bash
ffmpeg -hide_banner -loglevel error -i work/ep014_subs.mp4 \
  -c:v libx264 -profile:v high -level 4.1 -crf 20 -preset slow -pix_fmt yuv420p -r 30 \
  -vf "scale=1080:1920,setsar=1" -c:a aac -b:a 192k -ar 48000 \
  -movflags +faststart out/ep014_final.mp4 2>> work/ffmpeg.log; echo "rc=$?"
```

Целевые параметры: 1080×1920, 30 fps, H.264 High, AAC 192k, `+faststart`.
Проверь итог: `ffprobe -v error -show_entries format=duration,size -of default=nw=1 out/ep014_final.mp4`

## 2. Обложка

```bash
ffmpeg -ss 00:00:01.2 -i out/ep014_final.mp4 -frames:v 1 -q:v 2 out/cover.jpg
```
Выбирай кадр, где **видно лицо и эмоцию**, а не пустой план. Проверь кадр глазами через Read.
Если ни один кадр не годится — собери обложку через `generate_image` или возьми лучший кадр
и прогони через `upscale_image`.

Правило обложки: она должна быть понятна с размера ногтя большого пальца.

## 3. Описание и хештеги

Из `notes/script.md` возьми блок «Описание». Проверь:
- Первая строка — самостоятельный хук, работает **без** видео (её видно в ленте).
- 2–3 строки, не простыня.
- Открытая петля в конце: вопрос или «завтра — …».
- Хештеги: 5–8. Два широких, три нишевых, один-два брендовых сериала.
  Один и тот же брендовый тег во всех сериях — по нему собирается плейлист сериала.

## 4. Звук

- `tiktok_music_trending` — что сейчас в тренде.
- `tiktok_music_tune` — подгонка трека под ролик.

Осторожно: трендовый звук поверх собственной озвучки убивает речь. Если ролик разговорный —
трендовый звук идёт фоном на −20 dB или не идёт вообще. Тренд-звук хорош для роликов
без слов (сборки, «до/после», таймлапсы).

## 5. Прогноз перед публикацией

`virality_predictor` — оценка хука, удержания, риска оттока. Запускай **до** постинга:
если прогноз плохой из-за первых секунд, перемонтировать хук дешевле, чем сжечь выпуск.

Что делать с результатом:
- слабый хук → вернись в `video-script`, возьми другую формулу из `references/hooks-ru.md`;
- риск оттока в середине → в `video-edit` вырежи 3–5 секунд из провисающей части;
- слабый финал → добавь открытую петлю.

## 6. Постинг

```
tiktok_accounts        → проверить привязанный аккаунт
tiktok_connect         → если аккаунта нет
tiktok_prepare_publish → подготовка (описание, обложка, настройки)
tiktok_publish         → публикация
tiktok_publish_status  → подтверждение
```

Публикация — необратимое действие вовне. **Всегда показывай пользователю финальный текст
описания, хештеги и обложку и жди подтверждения перед `tiktok_publish`.**
Для Instagram Reels и YouTube Shorts автопостинга нет — отдай файл и текст, публикует человек.

## 7. Закрыть эпизод

1. Допиши строку в реестр эпизодов в `content/series-bible.md`
   (эп, дата, событие, хук, цифра дня, использованные приёмы).
2. Обнови `state.json`: `publish: done`.
3. Сохрани `out/caption.txt` с финальным описанием — пригодится для кросс-постинга.
