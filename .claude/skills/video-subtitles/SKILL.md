# Субтитры

Вертикальный контент смотрят без звука. Субтитры — не украшение, а основной канал.

## Порядок

```
речь → транскрипт с тайм-кодами → ASS со стилем → вжигание → проверка safe zone
```

## 1. Транскрипт с тайм-кодами по словам

Локально (бесплатно, лучший вариант — нужны тайм-коды **по словам** для karaoke):
```bash
ffmpeg -hide_banner -loglevel error -i work/ep014_up.mp4 -vn -ac 1 -ar 16000 work/audio.wav
whisper-cli -m models/ggml-medium.bin -l ru -ml 1 -osrt -of work/words work/audio.wav
```
`faster-whisper` (Python) с `word_timestamps=True` — тоже отлично.

Если whisper не установлен — предложи установку (`brew install whisper-cpp` /
`pip install faster-whisper`). Не пытайся угадать тайм-коды на слух из сценария:
рассинхрон субтитров заметнее, чем их отсутствие.

Если распознавания нет вообще, а текст известен из `notes/script.md` — сделай
пофразовые субтитры по тайм-кодам из сценария и **честно предупреди**, что синхронизация
приблизительная и её надо проверить глазами.

## 2. Стиль

Стиль выбирается один раз на сериал и дальше не меняется — это часть узнаваемости.

Базовые правила для 1080×1920:
- **Шрифт с кириллицей**: Montserrat Bold, Inter Black, Unbounded, Noto Sans Display.
  Bebas Neue / Archivo Black кириллицу не содержат — будут квадраты.
- **Размер**: 64–88 px. Меньше 56 — не читается в ленте.
- **Обводка**: 5–8 px чёрная + тень. Без обводки текст пропадает на светлом фоне.
- **Позиция**: центр по X, `MarginV` 420–560 px от низа — выше интерфейса площадки.
- **1–3 слова в строке**, максимум 2 строки. Длинные строки не читаются на скролле.
- **Заглавные** — только для акцентных слов, не для всего текста.

Готовые ASS-стили (5 пресетов: чистый, karaoke-подсветка, TikTok-жирный, минимал,
неоновый) + точные заголовки файла — в `references/ass-styles.md`.

## 3. Karaoke по словам

В ASS слово подсвечивается тегом `\k` (сотые доли секунды):
```
Dialogue: 0,0:00:03.10,0:00:04.60,Karaoke,,0,0,0,,{\k28}СЕГОДНЯ {\k22}ПЕРВЫЙ {\k30}ПЛАТЁЖ
```
Значение `\k` = длительность слова в сантисекундах, сумма должна равняться длине реплики.
Подсветка активного слова задаётся `SecondaryColour` в стиле.

Для «прыгающего» акцента используй `\t` с масштабом:
```
{\t(0,120,\fscx118\fscy118)\t(120,260,\fscx100\fscy100)}СЛОВО
```

## 4. Вжигание

```bash
ffmpeg -hide_banner -loglevel error -i work/ep014_up.mp4 \
  -vf "ass=work/subs.ass:fontsdir=./assets/fonts" \
  -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p \
  -c:a copy work/ep014_subs.mp4 2>> work/ffmpeg.log; echo "rc=$?"
```

Для SRT без стилизации:
```bash
-vf "subtitles=work/subs.srt:force_style='FontName=Montserrat,Fontsize=24,PrimaryColour=&H00FFFFFF,OutlineColour=&H00000000,Outline=3,MarginV=140'"
```
Внимание: в `force_style` `Fontsize` считается в масштабе `PlayRes`, а не в пикселях кадра —
поэтому для точного контроля используй ASS-файл, а не `force_style`.

## 5. Проверка

Вытащи 3 кадра с субтитрами и **посмотри на них**:
```bash
for t in 3 15 30; do ffmpeg -hide_banner -loglevel error -ss $t -i work/ep014_subs.mp4 \
  -frames:v 1 work/check_$t.jpg; done
```
Читай их через Read и проверь:
- [ ] Текст не залезает на лицо и не уходит за safe zone (снизу 420 px, сверху 250 px)?
- [ ] Кириллица отображается (не квадраты)?
- [ ] Читается на светлом и на тёмном фоне?
- [ ] Совпадает со звуком (сверь со сценарием)?
