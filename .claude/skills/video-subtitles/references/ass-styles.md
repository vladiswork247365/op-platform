# ASS-стили: готовые пресеты (1080×1920)

## Заголовок файла (обязателен, общий для всех пресетов)

```
[Script Info]
ScriptType: v4.00+
PlayResX: 1080
PlayResY: 1920
WrapStyle: 2
ScaledBorderAndShadow: yes

[V4+ Styles]
Format: Name,Fontname,Fontsize,PrimaryColour,SecondaryColour,OutlineColour,BackColour,Bold,Italic,Underline,StrikeOut,ScaleX,ScaleY,Spacing,Angle,BorderStyle,Outline,Shadow,Alignment,MarginL,MarginR,MarginV,Encoding
```

Цвет в ASS — `&HAABBGGRR` (alpha, blue, green, red), `AA=00` — непрозрачный.
`Encoding: 204` — кириллица.

---

## 1. Clean — чистый белый с обводкой (универсальный, безопасный выбор)

```
Style: Clean,Montserrat,74,&H00FFFFFF,&H00FFFFFF,&H00000000,&H80000000,-1,0,0,0,100,100,1,0,1,6,3,2,80,80,480,204
```
Белый текст, чёрная обводка 6, тень 3, снизу 480. Читается на любом фоне.

## 2. Karaoke — подсветка активного слова

```
Style: Karaoke,Montserrat,78,&H00B4B4B4,&H0000E5FF,&H00000000,&H80000000,-1,0,0,0,100,100,1,0,1,7,3,2,70,70,500,204
```
Неактивные слова серые (`PrimaryColour`), активное — жёлтое (`SecondaryColour`).

Реплика:
```
Dialogue: 0,0:00:03.10,0:00:04.60,Karaoke,,0,0,0,,{\k28}СЕГОДНЯ {\k22}ПЕРВЫЙ {\k30}ПЛАТЁЖ
```
Сумма `\k` (в сантисекундах) = длительность реплики. 1.5 с = 150.

## 3. Punch — жирный TikTok-стиль, 1–2 слова, с «прыжком»

```
Style: Punch,Unbounded,96,&H00FFFFFF,&H0000FFFF,&H00000000,&H00000000,-1,0,0,0,100,100,2,0,1,9,0,5,60,60,0,204
```
`Alignment: 5` — центр экрана. Одно-два слова, крупно, по центру.

Реплика с прыжком:
```
Dialogue: 0,0:00:05.00,0:00:05.45,Punch,,0,0,0,,{\t(0,110,\fscx120\fscy120)\t(110,240,\fscx100\fscy100)}17 ЗАЯВОК
```

## 4. Minimal — тонкий, для спокойного дневникового тона

```
Style: Minimal,Inter,58,&H00FFFFFF,&H00FFFFFF,&H00000000,&HA0000000,0,0,0,0,100,100,0,0,3,0,0,2,120,120,440,204
```
`BorderStyle: 3` — полупрозрачная плашка вместо обводки. Спокойно и аккуратно.

## 5. Neon — акцентный, для поворотов и цифр

```
Style: Neon,Unbounded,88,&H00FFFFFF,&H00FF00FF,&H00FF00C8,&H00000000,-1,0,0,0,100,100,1,0,1,5,6,2,70,70,520,204
```
Розово-фиолетовая обводка + тень 6 даёт эффект свечения. Не более 2 реплик на ролик —
иначе перегруз.

## Safe zones (вертикаль 1080×1920)

| Зона | Отступ | Что там у площадки |
|---|---|---|
| Снизу | 420–560 px | описание, кнопки, ник |
| Сверху | 250 px | статус-бар, кнопка «назад» |
| Справа | 180 px | лайки, комментарии, шаринг |

`MarginV: 480` при `Alignment: 2` — проверенный безопасный низ.
Ключевой текст (цифры, хук) держи в центральной трети кадра.

## Шрифты с кириллицей

Есть кириллица: **Montserrat, Inter, Unbounded, Noto Sans, Noto Sans Display, IBM Plex Sans,
Play, PT Sans, Roboto, Oswald, Caveat**.

Нет кириллицы (будут квадраты): **Bebas Neue, Archivo Black, Bangers, Permanent Marker,
Playfair Display, M PLUS Rounded 1c**.

Клади `.ttf` в `assets/fonts/` и передавай `fontsdir`:
```bash
ffmpeg -i in.mp4 -vf "ass=subs.ass:fontsdir=./assets/fonts" -c:a copy out.mp4
```

## Генерация ASS из SRT со словами

`whisper-cli -ml 1` даёт по одному слову на реплику. Дальше группируй по 2–3 слова:
берёшь начало первого слова и конец последнего как границы реплики, а длительности
слов превращаешь в `\k`-теги. Ровно так собирается karaoke-дорожка.

## Частые ошибки

| Симптом | Причина |
|---|---|
| Квадраты вместо букв | шрифт без кириллицы или не найден → `fontsdir` |
| Субтитры крошечные | нет `PlayResX/Y` в заголовке — масштаб считается от 384×288 |
| Текст под интерфейсом | `MarginV` меньше 420 |
| Обводка исчезла после апскейла | субтитры вжигались до апскейла — порядок нарушен |
| Съезжает тайминг | видео перекодировано с изменением fps после генерации субтитров |
