# content/ — рабочая папка контент-фабрики

Здесь живёт сериал: библия, эпизоды, исходники и рендеры.
Управляется скиллами категории `video-*` (см. `.claude/skills/README.md`).

## Структура

```
content/
  series-bible.md              ← сквозная арка сериала, цель, реестр эпизодов
  episodes/
    2026-08-02-ep001/
      raw/                     ← исходники как сняли (не редактируются)
      notes/context.md         ← что на кадрах: тайм-коды, дубли, брак  [video-ingest]
      notes/script.md          ← сценарий, хук, описание, хештеги       [video-script]
      notes/transcript.srt     ← распознанная речь
      work/                    ← промежуточные рендеры
      out/                     ← финал: ролик, обложка, caption.txt
      state.json               ← какие шаги пройдены
  assets/
    fonts/                     ← шрифты с кириллицей для субтитров
    music/                     ← музыкальные подложки
```

## Медиа не коммитятся

`.gitignore` в этой папке исключает видео, аудио и картинки — в репозитории
остаются только текстовые артефакты: библия, контекст, сценарии, состояние.
Именно они и есть память сериала; сами файлы храните локально или в облаке.

## Начать

```
/video:bible     — первый запуск: завести библию сериала
/video:day       — обычный день: от исходников до готового ролика
/video:status    — где мы сейчас
```
