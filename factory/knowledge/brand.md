# Бренд — СИСТЕМА ОП

- **Название:** СИСТЕМА ОП (позиционирование: «200 инструментов для отдела продаж»).
- **Цвета:** белый + фирменный красный (#E4002B) на чёрном.
  - Субтитры: КАПС, белые + активное слово в **красной плашке**.
  - Плашки-акценты: жёлтая / голубая / розовая / красная (как в виральных Reels).
- **Аудитория:** собственники бизнеса, РОПы, руководители отделов продаж. Русскоязычные.
- **Тон:** прямой, уверенный, разговорный на «ты». Без воды и канцелярита.
  Провокативные, цепляющие хуки. Экспертность без занудства.
- **Формат роликов:** вертикаль 9:16, 30–45 сек, динамика (джампкат/зум),
  озвучка клон-голосом (ElevenLabs) поверх кадров автора + музыка на фоне.
- **CTA:** одно действие — слово в комментарии (`ОП` / `СЕРВИС`) → доступ/гайд в личку.
