# factory/ — контент-завод (мозг системы)

Здесь живёт вся «умная» часть генерации контента, отдельно от движка монтажа.

```
factory/
  prompts/        промпты (сценарист и т.п.) — правятся как обычный текст
    scenarist.md  главный виральный промпт (30–45с, каждая фраза — хук)
  knowledge/      база знаний (её читает сценарист для точности и бренда)
    product.md    что такое СИСТЕМА ОП, фичи, боли аудитории
    brand.md      бренд, цвета, тон, формат
    virality.md   правила удержания >60% для RU-аудитории
  style.md        СТИЛЬ ОБЩЕНИЯ автора (заполняется по его примерам)
```

Как это работает: при написании сценария (`montage/scriptwriter.py`) система берёт
промпт из `prompts/scenarist.md`, подмешивает базу знаний и стиль автора — и Opus
пишет сценарий на бренде, по фактам продукта и «голосом» автора.

Правишь промпт/знания/стиль здесь — меняется поведение сценариста. Отдельный
репозиторий не нужен: всё обновляется вместе с ботом.
