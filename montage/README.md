# Montage — движок монтажа Reels-фабрики

Рендерит вертикальный (9:16) динамичный ролик из исходников по EDL-плану:
нарезка → рефрейминг в 1080×1920 → зум-панч на видео / Ken Burns на фото →
субтитры и хуки (белый + красная подсветка) → музыкальная подложка → склейка.

Всё на ffmpeg + Pillow, **без облака и без платных сервисов**. `drawtext` не нужен —
текст рисуется через Pillow и накладывается `overlay`, поэтому Reels-субтитры
полностью в фирменном стиле платформы.

## Установка (один раз)

```bash
pip install -r montage/requirements.txt
```

Тянет статический ffmpeg (`imageio-ffmpeg`), Pillow, `pillow-heif` (для `.HEIC` с айфона), numpy.
Всё с pypi — ничего компилировать не надо.

## Как получить исходники

Положи файлы в `montage/sources/` под теми именами, что указаны в EDL.
Их можно скачать из Google Drive «00 Исходники» (веб → «Скачать», или на своём
компьютере через синхронизацию Google Drive → папка проекта).

> В песочнице Claude сеть отрезана от Google Drive, поэтому здесь рендерят на
> сгенерированных тест-исходниках. На твоём компьютере (или на сервере с доступом
> к файлам) движок рендерит реальные клипы этой же командой.

## Запуск

```bash
python3 montage/render.py \
  --edl montage/examples/sosiski.edl.json \
  --src montage/sources \
  --out montage/out/reel.mp4
```

Флаги: `--edl` план, `--src` папка исходников, `--out` файл результата,
`--font` путь к своему TTF (по умолчанию ищет жирный кириллический шрифт в системе).

## Самопроверка движка (без реальных клипов)

```bash
python3 montage/make_test_sources.py                    # синтетические клипы+фото+музыка
python3 montage/render.py --edl montage/examples/test.edl.json --out montage/out/reel_test.mp4
```

## Авто-режим: «залил в папку Drive → само смонтировалось»

`autorun.py` следит за папкой исходников и при новых файлах сам строит план
(`auto_edl.py`) и рендерит ролик в папку выхода — без ручного EDL.

**Схема без облака и без оплаты** (Mac/ПК):
1. Поставь **Google Drive для компьютера** — папки Диска станут локальными, авторизация уже сделана.
2. Запусти обработчик (можно повесить на автозапуск):

```bash
python3 montage/autorun.py \
  --watch "~/Google Drive/Мой диск/АСП — Сериал 200 компаний/00 Исходники (съёмки)" \
  --out   "~/Google Drive/Мой диск/АСП — Сериал 200 компаний/01 Готовые ролики"
```

Залил ролик с телефона → Drive синхронизировал в папку → обработчик собрал
черновой динамичный reel → он появился в «01 Готовые» → синхронизировался на телефон.

На **сервере** (24/7 без твоего компьютера) — то же, но папки Диска подтягиваются
через `rclone` (`rclone copy gdrive:"…/00 Исходники" ./sources` по расписанию),
а результат — `rclone copy ./out gdrive:"…/01 Готовые"`.

> Авто-план даёт динамику картинки (нарезка, панчи, Ken Burns, музыка, хук из имени
> файла). Точные субтитры по смыслу речи — следующий модуль (транскрибация).

## Формат EDL (план монтажа)

```jsonc
{
  "output": { "w": 1080, "h": 1920, "fps": 30 },
  "music":  { "file": "music.m4a", "gain_db": -18 },   // опц., файл в sources/
  "beats": [
    {
      "src":   "clip.mov",        // имя файла в sources/ (видео или фото .jpg/.png/.heic)
      "in":    12.5,              // видео: старт выреза (сек)
      "out":   15.0,              // видео: конец выреза (сек)
      "dur":   0.6,               // фото: длительность на таймлайне (сек)
      "speed": 1.1,               // опц.: ускорение видео (звук тоже ускоряется)
      "motion":"punch",           // punch | kenburns_in | kenburns_out | none
      "punch": 1.08,              // опц.: сила зум-панча (для motion=punch)
      "audio": "keep",            // keep | mute (фото всегда без звука)
      "text": {                   // опц.: субтитр/хук
        "lines": ["при чём тут", "ПРОДАЖИ?"],   // ≤4 слова в строке
        "highlight": "продажи?",  // слово красным
        "pos": "lower",           // lower | center | upper
        "size": 84
      }
    }
  ]
}
```

Один `beat` = один кусок таймлайна. Порядок beats = порядок в ролике.
EDL для конкретного ролика соответствует `variant.script` в `reels.json`.
