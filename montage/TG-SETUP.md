# Телеграм-бот приёма роликов (до 2 ГБ) → монтаж → готовый Reel

Кидаешь видео боту в Telegram → он скачивает (до 2 ГБ), ставит в очередь,
монтирует вертикальный Reel (поджим пауз, динамичная нарезка, субтитры) и
присылает готовый ролик обратно.

Работает на **MTProto (Pyrogram)** — потому и держит гигабайтные файлы
(обычный Bot API качает только 20 МБ).

⚠️ Бот запускается **там, где есть ffmpeg и конвейер** — на твоём Mac (там же,
где стоит фабрика) или на сервере. Не в облаке.

## Настройка (~10 мин, один раз)

**1. Токен бота — @BotFather.**
В Telegram открой [@BotFather](https://t.me/BotFather) → команда **/newbot** →
придумай имя и username (кончается на `bot`) → получишь **токен** вида
`12345:AAE...`. Это `TG_BOT_TOKEN`.

**2. API ID и HASH — my.telegram.org.**
Зайди на [my.telegram.org](https://my.telegram.org) (вход по номеру телефона Telegram)
→ **API development tools** → создай приложение (App title любое, платформу — Other).
Получишь **api_id** (число) и **api_hash** (строка). Это `TG_API_ID` и `TG_API_HASH`.

**3. Прописать ключи.**
`montage/.env` (см. `montage/.env.example`), затем `chmod 600 montage/.env`:
```
TG_API_ID=1234567
TG_API_HASH=abcd1234ef...
TG_BOT_TOKEN=12345:AAE...
TG_ALLOW=@твой_username     # опц. — кому можно слать (пусто = всем)
```

**4. Запуск.**
- Проще всего — двойной клик по **`mac/reels-bot.command`** (сам поставит зависимости
  и спросит недостающие ключи).
- Или вручную:
  ```bash
  pip3 install -r montage/requirements-tg.txt
  python3 montage/tg_bot.py
  ```

**5. Пользоваться.**
Открой своего бота в Telegram → **/start** → кинь видео (с телефона или как файл).
Бот ответит статусом, смонтирует и пришлёт готовый Reel.

## Нужно на машине бота
- `ffmpeg` (движок монтажа) и зависимости фабрики — ставятся установщиком
  `mac/install-mac.command` (или `pip3 install -r montage/requirements.txt`).
- Стабильный интернет (гигабайты качаются/отдаются через Telegram).
