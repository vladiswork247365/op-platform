# 🎙 Озвучка твоим голосом — режим «говорю без звука»

Снимаешь ролик **молча** (или в шумном месте, звук неважен), даёшь **текст скрипта** —
а бот проговаривает его **твоим клон-голосом**, и звук + субтитры ложатся сами.

Нужно один раз подключить ElevenLabs: получить ключ и создать клон голоса.

---

## Шаг 1. Ключ ElevenLabs

1. Зайди на **elevenlabs.io** → зарегистрируйся (можно через Google).
2. Нажми на свой аватар справа сверху → **Profile + API key** (или **API Keys**).
3. Нажми **Create API Key** → скопируй ключ (длинная строка).

## Шаг 2. Создай клон своего голоса

Вариант А — прямо на сайте (проще):
1. Слева меню → **Voices** → **Add a new voice** → **Instant Voice Clone**.
2. Загрузи **1–2 минуты чистой записи** своего голоса (говоришь спокойно, без музыки
   и шума — подойдёт обычная запись на телефон).
3. Назови голос (например, «Мой голос») → **Add voice**.
4. Открой созданный голос → **скопируй его Voice ID** (в настройках голоса / три точки → Copy Voice ID).

Вариант Б — через бота-конвейер (одной командой в Терминале, из папки проекта):
```
python3 montage/eleven.py clone "Мой голос" ~/Downloads/образец1.mp3 ~/Downloads/образец2.mp3
```
Команда напечатает `voice_id: ...` — это и есть твой Voice ID.

## Шаг 3. Впиши ключ и голос

В Терминале (замени `КЛЮЧ` и `VOICE_ID` на свои — сами значения в чат никому не шли):
```
cd ~/Downloads/op-platform-main
printf 'ELEVEN_KEY=КЛЮЧ\n'        >> montage/.env
printf 'ELEVEN_VOICE_ID=VOICE_ID\n' >> montage/.env
```

Проверить, что всё видно:
```
python3 montage/eleven.py voices
```
Должен показать список голосов (значит, ключ работает).

---

## Как пользоваться в боте

1. Пришли боту **видео** (можно снятое молча).
2. Напиши или наговори: **«озвучь: <текст, который надо проговорить>»**
   (например: `озвучь: продажи — это забота о клиенте, а не впаривание`).
3. `/go` — бот озвучит текст твоим голосом, подложит под видео и сам поставит субтитры
   по словам. Хочешь ч/б — добавь слово «чёрно-белый».

Триггеры режима: «озвучь», «наложи голос», «без звука», «начитай», «проговори».

> Губы по видео не читаются — поэтому текст скрипта нужен обязательно. Точного
> совпадения губ с озвучкой не будет (это говорящая голова, а не дубляж), но для
> Reels выглядит естественно.

## Настройки голоса (по желанию, в montage/.env)
```
ELEVEN_STABILITY=0.45     # выше — ровнее/спокойнее, ниже — живее/эмоциональнее
ELEVEN_SIMILARITY=0.85    # похожесть на твой голос
ELEVEN_MODEL=eleven_multilingual_v2   # мультиязычная модель (русский)
```
