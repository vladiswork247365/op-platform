# Higgsfield MCP — интеграция (#5): тренд-аудио + оценка виральности + публикация

Higgsfield MCP уже подключён к среде, но пайплайн его не использует. Три точки
интеграции, все — read/act через MCP-инструменты (вызывает Claude-в-цикле, не сервер).

## Статус предусловий (проверено)
- **Кредиты Higgsfield: 0 (free-план)** → `virality_predictor` и генерация не запустятся.
- **TikTok-аккаунт не подключён** → `tiktok_music_trending` и `tiktok_publish` требуют `connector_id`.

Пока не выполнено это — #5 не активируется. Код-обвязка не поможет: нужны твои кредиты и подключение аккаунта.

## Что включается, когда выполнено

### 1. Оценка виральности до публикации (virality_predictor)
- Вход: загруженное видео (`media_upload` → `media_confirm`) или готовый job.
- Гоняем на A/B-вариантах ролика → attention/retention-скор, сила хука, риск оттока.
- Результат кладём в `reels.json` рядом с нашим Attention Score → выбор лучшего варианта.
- **Нужно:** кредиты Higgsfield.

### 2. Трендовое аудио (tiktok_music_trending)
- Список трендовых треков TikTok Commercial Music Library (фильтры genre/country/date_range).
- Пользователь выбирает трек → `music_sound_id` → подкладываем, `beat_sync.py` подтягивает нарезку к его битам.
- Работает только для DIRECT_POST (в черновиках TikTok музыка не сохраняется).
- **Нужно:** подключённый TikTok-аккаунт (`tiktok_accounts` → `connector_id`).

### 3. Публикация (tiktok_prepare_publish → tiktok_publish)
- Автопостинг готового ролика из «01 Готовые» с метаданными.
- **Нужно:** подключённый TikTok-аккаунт.

## Как подключить (твои шаги)
1. Пополнить кредиты Higgsfield (для virality_predictor).
2. Подключить TikTok: инструмент `tiktok_connect` → авторизация аккаунта.
3. Сказать мне «включай Higgsfield» — я вызову инструменты в цикле монтажа.

## Реестр
Эти инструменты уже учтены в `montage/viral_kit.py` (virality_score, trend audio) —
селектор их рекомендует; фактический вызов идёт через MCP при выполненных предусловиях.
