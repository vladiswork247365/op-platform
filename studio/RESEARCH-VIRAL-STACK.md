# Ресёрч: топ-репозитории виральных Reels → чего нам не хватает

> Многоагентный ресёрч (11 агентов, 9 категорий, **79 репозиториев**, ~534K токенов). Актуально на 2026.

## Вывод

Сильны в РЕНДЕРЕ и пост-обработке: ffmpeg-конвейер (нарезка/9:16/concat/xfade), движение (punch, zoompan, Ken Burns, бумеранг), auto-editor, faster-whisper с таймингами, karaoke-сабы через Pillow, beat-sync, Pexels b-roll, loudnorm -14 LUFS + цвет + retention-bar, YuNet-автофрейм, реестр viral_kit и методика Attention Score. Это крепкое механическое ядро 'собрать динамичный ролик из сырья'. Главные пробелы — в ИНТЕЛЛЕКТЕ отбора и в микро-удержании: (1) нет content-aware выбора моментов/хука — auto_edl рубит по таймеру, а не по силе момента (это #1 рычаг досмотра для монтажа из своего сырья); (2) сабы статичны на чанк, нет пословной анимации/пресетов; (3) нет зум-на-слове/velocity-рамп и звукового дизайна (SFX на резах) — дешёвые, но мощные приёмы удержания; (4) автофрейм статичен — нет слежения за активным спикером; (5) уже подключённый Higgsfield MCP (тренд-аудио, virality_predictor, публикация) простаивает. Вторичные пробелы: матирование фона/split-screen, семантика b-roll, обложки, 2.5D-параллакс, диаризация, планировщик постинга. Приоритет: сначала LLM-отбор моментов и анимированные сабы (максимальный impact на текущих навыках ffmpeg+Pillow+whisper), затем дешёвые zoom-on-keyword+SFX и активация Higgsfield MCP, потом ASD-реврейм и scene-detect. Topic-to-video генераторы (MoneyPrinterTurbo/ShortGPT) для вашего кейса 'монтируем СВОЁ сырьё' низкоприоритетны — брать из них только логику keyword→b-roll.

## 🎯 Приоритет внедрения (что первым)

**1. 1. Умный отбор моментов + добыча хука (LLM-скоринг виральности) — заменить механику auto_edl** — impact 9/10, усилия: medium  
Главный пробел: auto_edl.py берёт самый длинный клип и рубит фикс-биты по 3с, хук = имя файла/первые слова. Прогнать уже готовый транскрипт (.words.json) через ranking-промпт по virality-фреймворку Anil-matcha (хуки, opinion-bombs, конфликт, цитируемые фразы, story-peaks, польза → скор 0-100 + объяснение), сегментацию границ речи брать из clipsai TextTiling вместо таймера. Выбирать топ-N сегментов и ЛУЧШИЙ хук из речи, а не первое слово. Скор класть в reels.json Attention Score для A/B. Через OpenRouter/xAI (ключи уже есть) — новых зависимостей почти нет.

**2. 2. Настоящие пословные анимированные сабы + виральные пресеты (Hormozi/Bounce/Karaoke)** — impact 8/10, усилия: medium  
captions.py сейчас статичный PNG на чанк из 3 слов, красным лишь последнее — нет пословного появления. Апгрейд #1-фичи фабрики. Быстрый путь без ожидания Remotion: faster-whisper → pysubs2 ASS → ffmpeg с karaoke-тегами (\fscx/\fscy, pop/scale активного слова), связка ai-video-captions (6 пресетов). Позже перенести на Remotion (планируется) для glow/тускнения соседей как в vanta. Тайминги слов уже есть.

**3. 3. Зум-панч на ключевом слове + velocity-рампы (почти бесплатно на текущем стеке)** — impact 7/10, усилия: low  
highlight-слово уже вычисляется в word_cues, zoompan/setpts уже в render.py. Добавить punch-in (1.0→1.12 за ~0.3с) ровно на акцентном слове и плавные speed-ramp на стыках beat'ов вместо ровного speed=1.05. Ноль новых зависимостей, только код поверх render.py motion — быстрый видимый прирост ритма.

**4. 4. Звуковой дизайн: авто-SFX на склейках, появлении текста и highlight-слове** — impact 7/10, усилия: low  
Тайминги cut/cue уже известны движку. Добавить whoosh на xfade/cut, pop/ding на входе caption-cue, riser перед хуком через ffmpeg amix/adelay + набор CC0-ассетов (Mixkit/freesound), нормализовать в общем loudnorm-проходе. pycaps — референс триггеров по контенту. Дёшево, но заметно перезапускает внимание на каждом резе.

**5. 5. Активировать уже подключённый Higgsfield MCP: трендовый саунд + virality_predictor** — impact 7/10, усилия: low  
MCP в среде, но пайплайн его не зовёт. tiktok_music_trending → подложить тренд-саунд и подтянуть beat_sync.py к нему (сильный рычаг охвата). virality_predictor гонять на A/B-вариантах и на хуке до публикации, результат — в reels.json. Near-zero effort: инструменты уже доступны.

**6. 6. Динамический реврейм по активному спикеру (ASD) — вместо статичного YuNet** — impact 7/10, усилия: high  
autoframe.py держит медианную позицию крупнейшего лица на весь клип; для диалогов/разборов вдвоём камера не следит за говорящим. Внедрить пофреймовый трекинг со сглаживанием (EMA/Kalman) и переключение кропа между спикерами: путь openshorts (MediaPipe+YOLOv8) или clipsai (ASD-интеграция). Ключевая фича OpusClip для многолюдных съёмок.

**7. 7. Content-aware точки реза (PySceneDetect) + авто-обложка** — impact 6/10, усилия: low  
pip install scenedetect: ContentDetector даёт реальные границы сцен → auto_edl режет по ним (комбинируя со snap-to-beat), куски перестают начинаться в середине действия. Параллельно собрать авто-кавер (Pillow-текст + YuNet-лицо + rembg-cutout) — сейчас есть только SEO-тексты, а обложка решает CTR в сетке. Оба дешёвы и переиспользуют имеющиеся модули.

- **Авто-эмодзи/стикеры по смыслу речи с анимацией появления, синхронно со словом.** (5/10 · low) — Контент-driven эмодзи усиливают эмоцию фразы и добавляют 'нативности' платформы, повышая вовлечённость и комментарии. Дёшево при уже имеющемся word-тайминге.
- **Диаризация спикеров (кто и когда говорит) для диалоговых Reels — faster-whisper этого не даёт.** (5/10 · medium) — Разметка спикеров включает диалог-осознанные сабы (цвет/сторона по говорящему) и корректное переключение ASD-кропа — нужно для интервью/разборов вдвоём.

## Пропущенные категории техник (критик)

- B-ROLL / STOCK FOOTAGE AUTO-INSERTION — целая пропущенная категория. Никто в списке не делает семантический подбор и авто-вставку b-roll (Pexels/Pixabay/Storyblocks/YouTube CC) по ключевым словам транскрипта. Это ядро современного faceless-монтажа: keyword extraction из речи -> поиск клипов -> ранжирование релевантности -> вставка поверх talking-head в нужный момент. Репо: OpenMontage, sasoder/stockpile, AI B-roll generator.
- TOPIC-TO-VIDEO / FACELESS FACTORY (полный генеративный пайплайн) — в списке ТОЛЬКО клипперы (режут существующее видео). Полностью отсутствует класс 'из темы/ключевого слова -> LLM-сценарий -> TTS-озвучка -> стоковый футаж/AI-картинки -> субтитры -> BGM -> готовый Short'. Это самые звёздные репо ниши (MoneyPrinterTurbo ~62k, MoneyPrinter/V2, ShortGPT ~7.4k, Reddit-story боты).
- BEAT-SYNC / CUT-TO-BEAT / музыкально-driven монтаж — полностью отсутствует. BPM/onset-детекция (librosa/BeatThis), нарезка футажа строго по битам, определение структуры трека (intro/verse/drop/chorus) и синхронизация хайлайтов с дропом. Для AMV/GMV/phonk-эдитов и виральных монтажей это базовая техника.
- BACKGROUND REMOVAL / VIDEO MATTING / GREEN SCREEN — нет ни одного матирующего инструмента. Robust Video Matting (RVM), MODNet, BiRefNet: убрать/заблюрить/заменить фон в реальном времени, вырезать спикера для наложения на b-roll или split-screen. Отдельно от простого blurred-background reframe, который упомянут.
- SPLIT-SCREEN / 'SATISFYING' НИЖНЯЯ ПОЛОВИНА (gameplay/parkour/satisfying b-roll) — характернейший приём TikTok/Shorts для удержания (Subway Surfers, Minecraft parkour, soap cutting снизу). В списке нет композитинга двух дорожек в формат retention-content.
- SFX / ЗВУКОВЫЕ ЭФФЕКТЫ — авто-вставка whoosh/ding/pop/риверс на монтажных склейках, на появлении текста-хука, на пунчлайнах. Ни один репо этим не занимается (только BGM-микс в MoviePy/editly).
- SPEED RAMPS / VELOCITY EDIT / PUNCH-IN ZOOM — плавные ускорения-замедления (speed ramping), резкие zoom-in 'панч' на акцентных словах, Ken Burns на статичных кадрах. auto-editor умеет только тупое ускорение тишины; кинематографичных velocity-рамп и zoom-on-keyword нет.
- TREND AUDIO / ТРЕНДОВОЕ АУДИО — обнаружение трендовых звуков TikTok/Reels и подкладка под клип, привязка монтажа к популярному саунду. В опенсорсе почти нет (только проприетарные API типа Higgsfield tiktok_music_trending), но категорию нужно отметить как пропущенную.
- 2.5D ПАРАЛЛАКС / DEPTH-BASED MOTION из статичных изображений — depth estimation (MiDaS/Depth-Anything) + 3D Ken Burns (sniklaus/3d-ken-burns) для оживления фото/кадров. Отсутствует полностью.
- AUTO-ЭМОДЗИ / СТИКЕРЫ / GIF-ОВЕРЛЕИ по контенту — контент-driven вставка эмодзи и стикеров (частично есть в pycaps как фича, но как отдельная техника-категория с семантическим триггером и анимацией появления не покрыта).
- THUMBNAIL / COVER / обложка — авто-генерация обложки-кавера (первый кадр + крупный текст + лицо-cutout + стрелки), критично для CTR. В списке нет генерации превью, только SEO-тексты.
- ПУБЛИКАЦИЯ / МУЛЬТИ-ПЛАТФОРМА / ПЛАНИРОВЩИК — авто-загрузка и расписание постинга в TikTok/Reels/Shorts с метаданными (Reddit-боты это делают). Оркестрация распространения как категория отсутствует.
- AI-ПРЕЗЕНТЕР / TALKING AVATAR / LIP-SYNC — генеративный говорящий аватар (SadTalker, Wav2Lip, Hedra-class) и липсинк под дубляж. Дубляж упомянут (openshorts/ElevenLabs), но синхронизация губ и AI-ведущий — нет.
- VIRALITY PREDICTION / HOOK SCORING как отдельная ML-задача — не просто LLM-ранжирование хайлайтов, а предсказание retention/attention curve и A/B хуков (Higgsfield virality_predictor). Как отдельный класс инструментов пропущено.
- AUTO COLOR GRADING / LUT / нормализация картинки — авто-цветокоррекция и применение LUT-пресетов под 'кинематографичный' вид. Не покрыто.
- МУЗЫКА-ГЕНЕРАЦИЯ (не подбор) — генеративный BGM (MusicGen/Stable Audio) вместо готовых треков. Категория отсутствует (FFCreator/editly только микшируют существующее).
