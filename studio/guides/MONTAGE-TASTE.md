# MONTAGE-TASTE — канон вкуса (из Talgat AI Video Studio)

Железные правила монтажа и ревью-чеклист. Проверять КАЖДЫЙ рендер покадрово ДО показа.

## Железные правила

- **Один ритм** на видео; смысловой бит ≥ 1 с; контраст темпа: burst → hold.
- **Хук ≤ 1.5 с**, работает на mute; обрыв на пейоффе, без аутро.
- **≤ 2 шрифта** в кадре, **≤ 3 цвета**. Казахские глифы проверять (Қ Ғ Ұ Ү Ң Ә Ө І).
- Слово **помещается в кадр целиком** всю свою жизнь.
- **Hard cut на действии** = база; спецпереход 1–2 на видео, мотивированный.
- **SFX на 10–20 мс раньше** картинки; 1 событие = 1 звук.
- **Safe zones 9:16**: снизу 320px, справа 120px — текст туда нельзя.
- Текст/VO не противоречит картинке; факты сверять с заказчиком.
- **Стиль = грамматика, не ассеты.** Палитру/фигуры/тайлы генерить заново под тему. Чужие текстуры в кадре = провал.

## Громкость (только замер LUFS, не «на глаз»)

- Голос: **−16…−18 LUFS**
- Музыка: **−13 LU от голоса**
- SFX: **−8…−12 LU**
- ebur128 врёт на окнах < 0.4 с → короткие SFX мерить по RMS.

## Пайплайн «нарезка подкаста»

1. Транскрипт: аудио → Scribe (word timestamps, rus/kaz).
2. Поиск сегментов: кластеризация ключевых слов (окно 45 с), куски 40–70 с с законченной мыслью, хук + пейофф обязательны.
3. Нарезка: ffmpeg по границам слов (`libx264 -crf 18`, 30 fps).
4. Автофрейминг: `autoframe.py clip.mp4` → crops.json (по лицам).
5. Монтаж: караоке-сабы (CAPS, ≤3 слова, активное слово жёлтым, y≈65%), хук-плашка 0–2 с, kick-zoom на склейках, зерно, обрыв на пейоффе.
6. Ревью-сетка: `ffmpeg -vf "select='not(mod(n,15))',scale=180:-1,tile=7x6"`.

## Пайплайн «кинетик» (текст-видео без съёмки)

1. Сценарий: хук ≤ 1.5 с (3–6 слов) → 3–5 битов → панч-финал + CTA.
2. VO (опц.): TTS stability 0.0; ускорение без питча `silenceremove + atempo=1.15`.
3. Музыка: «biggest climax in final five seconds, NO quiet outro»; биты — `detect_beats`; каты и слова на кики.
4. Композиция: слова на битах, спринги (панч: damping 12, stiffness 200), один приём на сцену, у SVG-эффекта обязателен end.

## Накопленные грабли

- Шрифты Black часто variable с дефолтом Thin → вес задавать явно.
- rembg вырезает ВСЕХ людей → решать композицией.
- i2v подменяет лицо → identity держать стиллами.
- OffthreadVideo без Sequence застывает → оборачивать в Sequence.
- Клон-голос на stability 0.0 дрейфует → контроль текста через Scribe.
- Мелкие исходники нельзя в cover на весь кадр → проверять разрешение до сборки.

## Ревью-чеклист (перед показом)

- [ ] Хук цепляет за ≤ 1.5 с и на mute
- [ ] Один ритм, есть контраст burst → hold
- [ ] Все слова целиком в кадре, вне safe-zone
- [ ] ≤ 2 шрифта, ≤ 3 цвета; глифы ок
- [ ] LUFS замерены (голос −16…−18, музыка −13 LU, SFX −8…−12)
- [ ] SFX раньше картинки на 10–20 мс
- [ ] Обрыв на пейоффе, без аутро
- [ ] Просмотрено покадрово по ревью-сетке
